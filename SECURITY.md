# Security policy

## Supported versions

Security fixes are made on `main` and included in the next tagged release. Only
the latest tagged release is supported.

## Reporting a vulnerability

Use GitHub's **Security → Report a vulnerability** form to open a private
security advisory with the maintainer:

https://github.com/cptbucky/node-red-home-automation/security/advisories/new

Include the affected component and version, impact, reproduction steps, and any
suggested mitigation. Remove credentials, private addresses, entity IDs, flow
exports, and installation topology before submitting evidence.

Do not open a public issue for a suspected vulnerability. You should receive an
initial response within seven days. Confirmed vulnerabilities will be fixed and
disclosed through a GitHub Security Advisory and tagged release.
