Behavioral guarantees

Stale work is inert

Timers, command results and observations carry generation identity and cannot complete a newer request.

Readiness is honest

Mandatory targets require fresh observations. Unsupported or unobservable capabilities remain explicit.

Manual control is preserved

Unsolicited target changes become ownership evidence rather than a reason to fight the user.

Volume control has one owner

Absolute and relative requests share receiver bounds, observed confirmation and an explicit release point for later manual adjustment.

Recovery is bounded

Restart refreshes observations without blindly replaying state-changing commands.

Failure is actionable

Retries, fallback use, target availability and transition latency remain visible through one state contract.

Policies stay transport-neutral

Activity profiles name semantic outcomes; adapters own protocol-specific operations.
